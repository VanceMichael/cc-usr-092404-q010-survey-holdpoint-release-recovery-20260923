# 廊桥测绘基线仲裁库

工程以 Fastify 和 TypeScript 提供古廊桥分段顶升**施工停检点测量放行**后端，
使用 Node.js 22 内置 SQLite API 访问 `data/bridge_baselines.sqlite3`。可通过
`DATABASE_PATH`、`HOST`、`PORT` 调整本地运行位置。

```bash
npm ci
npm run db:migrate
npm test
npm run build
npm start
```

## 领域能力

- 为工作区登记停检点：前置工序、控制点集合、位移/沉降容差、观测时效；
- 承包方证据包提交即固定原始观测摘要、基线与仪器校准版本，旧包永不覆盖；
- 缺项、测量超差、观测时效、上游未放行、相邻区域租约冲突沿工序依赖传播到看板；
- 测量复核人先签、监理后签，两个角色均不能批准自己提交的材料；
- 整改以新证据包关闭偏差；人工豁免带期限与依据；
- 观测补录、校准撤销、设计换版：未开工放行撤销（原决定保留），施工中挂起
  现场复核，已执行转风险评估；
- 重叠工作区施工租约独占；签署面对版本变化须重新确认；
- 批量校核支持中断处恢复；一次设计换版按待放行/施工中/已执行分别列出处置
  去向与波及班组。

规则、状态机、阻断归因码与接口清单见 [`docs/放行规则.md`](docs/放行规则.md)，
基础不变量见 [`docs/领域约定.md`](docs/领域约定.md)。

## 代码布局

接口、领域服务、迁移和启动验证分别位于 `src/http`、`src/domain`、`migrations`
与 `test`，应用不连接远程对象存储或消息系统。
