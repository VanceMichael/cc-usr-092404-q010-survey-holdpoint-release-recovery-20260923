# 领域约定

原始采集包不可覆盖；构件对应关系随基线版本发布；隔离数据只有在摘要、序号和坐标信息完整后才能参与仲裁。

停检点测量放行在此基础上的约定：

- 证据包只追加新版本，原始观测摘要、基线与仪器校准版本在提交时固定；
- 测量复核人先签、监理后签，任何人不得批准自己提交的材料；
- 缺项、超差、上游未放行与相邻区域冲突沿工序依赖传播到放行看板；
- 整改以新证据包关闭偏差，人工豁免必须带期限与依据；
- 补录、校准撤销与设计换版撤销未开工放行（原决定留存），已执行工序转风险评估；
- 重叠工作区施工租约同一时刻只准一个，版本变化后签署必须重新确认。

详见 [放行规则.md](放行规则.md)。
